# Med Study Planner

Crie a base de uma aplicação web chamada Residência Planner, voltada à organização dos estudos para provas de residência médica. A inspiração funcional pode vir de plataformas como Estudei e RevEasy, mas crie identidade visual, componentes e experiência próprios, sem copiar textos, marca ou layout.

Use React, TypeScript, Tailwind CSS e componentes reutilizáveis. A aplicação deve ser mobile-first, responsiva e funcionar muito bem em celular, tablet e desktop. Adote visual minimalista, moderno e profissional, com fundo claro, azul-petróleo como cor principal, verde para metas concluídas, amarelo para pendências e vermelho discreto para revisões atrasadas. Inclua modo escuro.

Crie um layout autenticado com barra lateral no desktop e navegação inferior no celular. Inclua as páginas:

Visão geral;

Conteúdos;

Sessões de estudo;

Questões;

Revisões;

Planner;

Metas e desempenho;

Configurações.

Na Visão geral, mostre inicialmente cartões de horas estudadas, questões realizadas, percentual de acertos, revisões pendentes e progresso das metas. Inclua uma lista “Hoje” com estudos e revisões planejados. Use dados simulados apenas para demonstrar o layout e organize o código para substituir esses dados pelo backend nos próximos passos.

Crie estados vazios, loading skeletons, mensagens de erro e feedback visual para ações. Preserve uma hierarquia visual limpa e evite excesso de elementos. Não implemente ainda regras complexas de revisão; nesta etapa, entregue a estrutura visual, rotas e componentes principais sem quebrar a navegação.

Critérios de aceite: todas as páginas devem abrir sem erro; o menu deve indicar a página ativa; o layout deve se adaptar corretamente ao celular; e os componentes devem ser reutilizáveis.
